# 印刷套准复核台

先有**机台名册**，再送复核：印刷员登记机台称呼并标记能否使用。接口把印张偏差连同**入队时冻结的机台称呼**放进待处理队列；另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

## 机台名册规则

- 印刷员登记机台称呼（如「甲机」），称呼唯一；登记后即可使用。
- 入队时**必须挑选一台仍可使用的机台**，否则整笔退回：
  - 没选 / 名册里没有 → `缺机台`；
  - 选到的机台已停用 → `机台已停`。
- 机台称呼在入队那一刻**写入任务并冻结**：事后把名册停用、改名都不会改掉旧任务上的称呼。
- 可随时停用一台机台；停用后名册留下停用记录，旧任务的冻结称呼与样张仍可翻阅。
- 只读账号（checker）能翻名册、停用记录与冻结称呼，但**不能登册、不能停用、不能送复核**。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/machines` | 登录即可 | 名册（含停用记录） |
| POST | `/api/machines` | 印刷员 | 登记一台可使用机台 |
| POST | `/api/machines/{id}/stop` | 印刷员 | 停用机台 |
| GET | `/api/jobs` | 登录即可 | 任务（含冻结的 `machine_name`） |
| POST | `/api/jobs` | 印刷员 | 送复核，须带可使用机台 `machine_id` |

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准；两笔都冻结在「一号机」。
2. 打开**机台名册**页：上区是可使用机台（可登记、停用），下区是停用记录与已冻结样张；不是只在首页格子里塞机台名。
3. 登记「甲机」为可使用后，回队列选甲机送一张「封面」（青偏差 0.05）：应进**待处理**，随后正常出结论。
4. 到名册把「甲机」改成停用，再选甲机送一张：应被**整笔退回**，提示「机台已停」。
5. 不选机台直接送：退回「缺机台」。
6. 翻开第 3 步那笔成功任务，冻结称呼**仍是甲机**，不随后续停用改变。
7. 退出改用 checker 登录：能看名册与冻结称呼，但没有登记、停用、送复核入口。
