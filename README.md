# 印刷套准复核台

送复核之前要先有机台名册：印刷员登记机台称呼并标记能否使用，入队时必须挑选一台仍可使用的机台，否则整笔退回并说明缺机台还是机台已停。机台称呼写入任务即冻结，事后把名册停用也改不掉旧任务上的称呼。

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

页面分两块导航：「复核队列」是送检与结论列表；「机台名册」上区列可使用机台，下区列停用记录与已冻结样张。只读账号能翻名册与冻结称呼，不能登册也不能送检。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准（这两条是名册建立前的旧样张，机台列为空）。
2. 打开「机台名册」，登记甲机为可使用；上区出现甲机。
3. 回「复核队列」，送一条挂甲机的封面印张：状态先是待处理，随后出结论。
4. 名册里把甲机改成停用，再送挂甲机的印张：整笔退回，提示机台已停。
5. 不挑机台直接送：整笔退回，提示缺机台。
6. 翻开先前成功那笔，机台列的冻结称呼仍是甲机；名册下区「已冻结样张」里也看得到。
7. checker 能翻名册与冻结称呼，但没有登记机台按钮，也没有送复核按钮。
